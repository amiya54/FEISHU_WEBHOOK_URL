#  放置路径：config/frequency_words.txt
#
#  ★ 每组第一行的 [组名] 是「显示名称」，有两个作用：
#      1) 推送消息里的分组标题
#      2) AI 分析时喂给模型的分组名
#    不写它的话，分组名会退化成一长串关键词拼接，既难看，
#    也会让 AI 拿着这串词去瞎联想。所以每组都必须写。
#
#  语法：
#    普通词  —— 命中即归入本组（同组内多词为「或」关系）
#    +词     —— 必须同时包含，用于收窄范围
#    !词     —— 命中则排除该条
#    @数字   —— 限制本组最多显示 N 条
#    空行    —— 分隔不同主题组（组内不可有空行）
#
#  ⚠️ 关键词同时作用于「热榜」和「RSS」两条数据线。
#     因为英文 RSS 源占比高，中英文关键词都要写。
#
#  📌 组顺序 = 推送/报告里的显示顺序（内容为空的组不显示）。
#     本版为【法规规范优先】版：把法规与国际公约排到第 1 组、
#     船级社规范排第 2 组，让命中这些词的新闻被优先归档，
#     在双周报里形成靠前的「法规规范」板块。
#
#  ⚠️ 双周报取样窗口是 14 天，命中量约为单日的十倍。
#     若某组刷屏（例如「企业动态」），在该组标题后加 @25 限制条数。
#
#  ⚠️ 另一个坑：程序的「当前区域」状态是跨组持久的。
#     一旦写了 [GLOBAL_FILTER]，后面所有组都会被当成全局过滤词，
#     必须再单独写一个 [WORD_GROUPS] 才能切回来。本文件刻意没有使用该区。
