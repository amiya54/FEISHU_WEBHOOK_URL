#  ★ 每组第一行的 [组名] 是「显示名称」，有两个作用：
#      1) 推送消息里的分组标题
#      2) AI 分析时喂给模型的分组名
#    不写它的话，分组名会退化成一长串关键词拼接
#    （如 "IMO / MEPC / International Maritime Organization / ..."），
#    既难看，也会让 AI 拿着这串词去瞎联想。所以每组都必须写。
#
#  语法：
#    普通词  —— 命中即归入本组（同组内多词为「或」关系）
#    +词     —— 必须同时包含，用于收窄范围
#    !词     —— 命中则排除该条
#    @数字   —— 限制本组最多显示 N 条
#    空行    —— 分隔不同主题组（组内不可有空行）
#
#  ⚠️ 关键词同时作用于「热榜」和「RSS」两条数据线。
#     因为英文 RSS 源占比高，中英文关键词都要写。
#
#  📌 组顺序 = 推送里的显示顺序（内容为空的组不显示）。
#     本次把技术类组（替代燃料 / 节能技术 / 低碳技术前沿）排到最前，
#     让技术消息优先出现在消息顶部；法规与市场类放在其后。
#
#  ⚠️ 另一个坑：程序的「当前区域」状态是跨组持久的。
#     一旦写了 [GLOBAL_FILTER]，后面所有组都会被当成全局过滤词，
#     必须再单独写一个 [WORD_GROUPS] 才能切回来。本文件刻意没有使用该区。
