令牌怎么弄？（只需一次）
  1. 打开 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Token name 随意；Expiration 建议 90 天；Resource owner 选 amiya54。
  3. Repository access 选 Only select repositories，只勾 FEISHU_WEBHOOK_URL 和 ship-coating-radar。
  4. Permissions → Repository permissions → Contents: Read and write（其余全部 No access）。
  5. 生成后复制，粘到上面，点「记住本机」。令牌只存在这台浏览器，不随页面上传。

看不到 Fine-grained tokens 入口？用 classic token 也行，只需勾 repo 一项，但权限更大，建议优先细粒度令牌。
